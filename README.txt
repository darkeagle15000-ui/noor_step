JEJAK NUR — PROTOTIPE 0.1

CARA MENJALANKAN
1. Simpan index.html, style.css, dan script.js di dalam satu folder.
2. Buka index.html dengan browser (Chrome, Firefox, atau Edge).
3. Tidak perlu instalasi atau API key. Koneksi internet hanya dipakai untuk memuat font opsional; game tetap bisa dimainkan tanpa font tersebut.

KONTROL
- WASD atau tombol panah: bergerak
- E atau Enter: berinteraksi
- I: buka tas
- J: buka jurnal
- H: buka panduan
- Escape: tutup jendela
- Ponsel: gunakan D-pad dan tombol INTERAKSI di bawah game

FITUR PROTOTIPE
- Peta top-down pixel art kota oasis Nuraya
- Karakter dengan gerakan 4 arah dan kamera mengikuti pemain
- NPC, masjid, pasar, kebun, sumur, perpustakaan, penginapan, dan jembatan
- Sistem waktu simulasi, pergantian pencahayaan, dan pengingat waktu salat simulasi
- Pasar untuk membeli barang, tas, jurnal misi sederhana, dan penyimpanan lokal

Catatan: Jadwal salat pada prototipe ini adalah jadwal simulasi fiktif untuk gameplay, bukan jadwal ibadah nyata.
